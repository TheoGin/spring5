
## 修复 TxTest.buyGoodsByTxISOLATIONTest 事务隔离级别报错

- 现象：`@Transactional` 加 `isolation = Isolation.READ_COMMITTED` 后报 `Unknown system variable 'tx_isolation'`；不加则正常。
- 原因：lib 中 mysql-connector-java 5.1.7（`com.mysql.jdbc.Driver`）通过 `SELECT @@session.tx_isolation` 读隔离级别，本地 MySQL 8.4+ 已移除该系统变量（改名为 `transaction_isolation`）。不加 isolation 时 Spring 不触碰隔离级别，故不触发。
- 修复：旧 jar 改名为 `mysql-connector-java-5.1.7-bin.jar.bak` 移出 classpath；从 D:/programs/Java/Maven/repository 拷入 `mysql-connector-j-8.3.0.jar`（IDEA lib 为 jarDirectory 引用，自动生效）；`src/jdbc.properties` 改为 `com.mysql.cj.jdbc.Driver`，URL 追加 `serverTimezone=Asia/Shanghai&useSSL=false`。
- 验证：命令行单独运行 `buyGoodsByTxISOLATIONTest` 通过（两次读取价格 15.0，runCount=1 failures=0）。
- 备注：用户 Maven 安装在 D:/programs/Java/Maven，本地仓库为 D:/programs/Java/Maven/repository。
